# Trackly — Order Tracking

หน้าติดตามออเดอร์ที่พัฒนาด้วย Next.js App Router, TypeScript และ Tailwind CSS ออกแบบให้ใช้งานได้ทั้งมือถือและเดสก์ท็อป

## เริ่มต้นใช้งาน

ต้องมี Node.js 18.17 ขึ้นไป

```bash
npm install
npm run dev
```

เปิด [http://localhost:3000](http://localhost:3000) ในเบราว์เซอร์

```bash
npm run build
npm start
```

## ความสามารถ

- ค้นหาออเดอร์ด้วยรูปแบบ `ORD-` ตามด้วยตัวเลข 13 หลัก เครื่องหมายขีด และตัวเลข 3 หลัก
- แสดงสถานะอยู่ในคิว, กำลังดำเนินการ, เสร็จสิ้น และรอชำระเงิน
- แยกออเดอร์ปัจจุบันและออเดอร์ที่ผ่านมา พร้อมคัดลอกหมายเลข
- รองรับ Loading, Error และ Empty state รวมถึงการใช้งานบนมือถือ
- ข้อมูลในตัวอย่างเป็น mock data สำหรับสาธิต สามารถค้นหาออเดอร์ที่แสดงในรายการได้

## SEO และ Semantic HTML

กำหนดชื่อหน้าและคำอธิบายภาษาไทยใน metadata, ระบุ `lang="th"`, ใช้ `main`, `header`, `nav`, `section`, heading ตามลำดับ และ label ที่เชื่อมกับช่องกรอกเพื่อให้โปรแกรมอ่านหน้าจอใช้งานได้ การออกแบบหน้าใช้ CSS และไม่มีภาพตกแต่งขนาดใหญ่ จึงลดการดาวน์โหลดทรัพยากรที่ไม่จำเป็น

หน้า Order Tracking ควรตั้ง `noindex, nofollow` เพราะอาจแสดงรหัสออเดอร์และข้อมูลสถานะที่ผูกกับผู้ใช้ ไม่ใช่เนื้อหาสาธารณะที่ควรปรากฏในผลค้นหา ทั้งนี้ระบบจริงควรตรวจสอบสิทธิ์ก่อนส่งข้อมูลออเดอร์จากฝั่งเซิร์ฟเวอร์
